# 离线预览检查

用 `page.mjs entry --project <PROJECT_DIR>` 确认正式入口，浏览器直接打开它返回的本地文件。等待页面挂载完成（`#app` 的 `data-tui-ready` 为 `ready`），检查页面错误和意外 HTTP 请求。

- 新页和结构调整：按目标窗口尺寸查看首屏、标题与各栏对齐、真实长内容的折行和截断、控件状态、滚动归属及溢出。复杂页再用 Pattern 最小支持窗口复查，并保存代表性状态截图。
- 操作一条完整主流程，核对触发、状态变化、结果和恢复路径。跨栏选择要核对两栏指向同一对象。需求包含空态或错误恢复时验证相应状态。
- 局部修改：打开同一正式入口，检查修改处及它影响的操作。发现问题回到页面输入或业务文件修正，再检查受影响的状态。

生成和打包通过、浏览器交互通过、视觉检查完成分别记录。视觉记录写明视口、状态和对照对象。环境无法打开页面时保留具体原因与待查项目。
